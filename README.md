# SmartPCOD 🌸

AI-based PCOD Risk Detection System using Machine Learning.

## Technologies

* Python
* Flask
* HTML
* CSS
* JavaScript
* MySQL
* Random Forest

## Features

* Enter health details
* Predict PCOD risk
* Low / Medium / High Risk
* Prediction history

## How to Run

```bash
pip install flask pandas numpy scikit-learn joblib mysql-connector-python
```

```bash
python train_model.py
```

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
